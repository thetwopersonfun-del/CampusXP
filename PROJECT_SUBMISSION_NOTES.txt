CampusXP Project Submission Notes

Project Description:
CampusXP is a full-stack student engagement platform designed to help students improve academically by sharing study materials, completing missions, earning XP, tracking progress, adding friends, and messaging classmates.

The goal of the project is to motivate students to help each other. Students can upload summaries, notes, slides, study guides, and revision material. They can also complete missions that are related to useful academic actions, such as helping classmates or sharing practice material.

Main Features:
- User registration and login
- JWT authentication
- XP and level system
- Daily and weekly missions
- Automatic mission completion based on real platform actions
- Feed for notes, summaries, slides, and study guides
- Like system
- Leaderboard
- Rewards page
- Friend requests
- Messaging between friends
- Progress tracking between friends
- Notifications
- Alex assistant for study tips, XP, missions, rewards, and platform help
- Search bar to find students on the platform

Requirements:
Before running the project, install:
- Node.js
- PostgreSQL
- VS Code or any code editor
- Git

Technologies Used:

Backend:
- Node.js

Database:
- PostgreSQL

Database Setup:
Open PostgreSQL SQL Shell and run:

CREATE DATABASE campusxp;
\c campusxp;

Then create the required tables:
- users
- posts
- likes
- missions
- user_missions
- rewards
- user_rewards
- notifications
- friendships
- messages

Backend Setup:
Open a terminal and go to the backend folder:

cd backend

Install dependencies:

npm install

Create a .env file inside the backend folder:

PORT=5000
DATABASE_URL=postgresql://postgres:YOUR_PASSWORD@localhost:5432/campusxp
JWT_SECRET=campusxp_super_secret_key_change_this_in_production
JWT_EXPIRES_IN=7d
CLIENT_URL=http://localhost:5173

Replace YOUR_PASSWORD with your PostgreSQL password.

Start the backend:

npm run dev

The backend runs on:
http://localhost:5000

To test the backend, open:
http://localhost:5000/health

Frontend Setup:
Open a second terminal and go to the frontend folder:

cd frontend

Install dependencies:

npm install

Start the frontend:

npm run dev

The frontend usually runs on:
http://localhost:5173

If Vite opens another port, such as 5174, use that link instead.

How to Run the Full Project:
You need two terminals running at the same time.

Terminal 1 — Backend:
cd backend
npm run dev

Terminal 2 — Frontend:
cd frontend
npm run dev

Then open:
http://localhost:5173

Important Notes:
- The .env file is not uploaded to GitHub for security reasons.
- The backend must be running before using the frontend.
- PostgreSQL must be installed and the campusxp database must exist.
- Missions are completed automatically through real user actions.
- Students cannot manually claim XP by clicking missions.
- Alex assistant currently works as a rule-based assistant, so it does not require paid AI API credits.
